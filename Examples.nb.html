Slide 11-13: Data Visualization

Show how basic graphs can be made using R

Steps:

1. Create a Scatter Plot

plot(mtcars$mpg, mtcars$hp,
    main = "MPG vs Horsepower",
    xlab = "Miles per Gallon",
    ylab = "Horsepower",
    col = "blue",
    pch = 19)

2. Create a Histogram

hist(mtcars$mpg,
    main = "Distribution of MPG",
    xlab = "Miles per Gallon",
    col = "lightgreen",
    border = "black")

3. Use ggplot2

library(ggplot2)

ggplot(mtcars, aes(x = mpg, y = hp)) +
  geom_point(
    aes(color = factor(cyl), size = wt),
    alpha = 0.8
  ) +
  geom_smooth(method = "lm", se = FALSE, color = "black", linetype = "dashed") +
  scale_color_brewer(palette = "Set2", name = "Cylinders") +
  scale_size_continuous(name = "Weight") +
  labs(
    title = "Relationship Between Miles per Gallon and Horsepower",
    subtitle = "Colored by cylinder count and sized by car weight",
    x = "Miles per Gallon (mpg)",
    y = "Horsepower (hp)",
    caption = "Data: mtcars"
  ) +
  theme_minimal(base_size = 14) +
  theme(
    plot.title = element_text(face = "bold", size = 18),
    plot.subtitle = element_text(size = 13, color = "gray30"),
    plot.caption = element_text(size = 10, color = "gray40"),
    panel.grid.minor = element_blank(),
    panel.grid.major = element_line(color = "gray90"),
    legend.position = "right"
  )

Generating Data of a Given Distribution

  1. Generate random (r-) Normally-distributed data (-norm)
set.seed(123)  # for reproducibility

x <- rnorm(1000, mean = 0, sd = 1)
  1. Overlay the theoretical density (d-) curve to the Normal distribution (-norm)
# Histogram of data
hist(x, breaks = 30, probability = TRUE,
     main = "Normal Distribution", col = "lightblue")

# Density function overlay
curve(dnorm(x, mean = 0, sd = 1), add = TRUE, col = "red", lwd = 2)
  1. Determine the probability that X ≤ 1.96 (pnorm = inverse of qnorm)
pnorm(1.96, mean = 0, sd = 1)
  1. Find the 97.5% quantile (qnorm = inverse of pnorm)
qnorm(0.975, mean = 0, sd = 1)
